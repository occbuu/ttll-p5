# ttll-p5

Code and ward-level aggregate inputs for the revised study of administrative rescaling and jurisdictional exposure in the former Thu Duc City, Ho Chi Minh City. This branch reproduces the 12-ward proposal comparison, 625 secondary split-allocation scenarios and article figures. The historical survey-based workflow remains available in the immutable `v1.0.0` tag; survey data are not used in the revised paper.

## Scope and interpretation

The inputs represent 34 former wards and 12 successor-ward proposal profiles. Twelve legal successor wards are assembled from the ward-allocation crosswalk in `sensitivity.py`. Four former wards are assigned to two successors. Their true fractional allocation is unavailable, so the code varies each share over 0, 0.25, 0.5, 0.75 and 1: **625 deterministic scenarios**, including equal shares. The output ranges are *scenario envelopes, not confidence intervals*. OSM categories represent mapped stock and include wards with zero mapped features. Proposed positions describe a staffing plan; the analysis does not estimate realised staffing, service quality or causal reform effects.

## Inputs

The three study aggregate tables are in `data/`. They contain ward totals, with no person-level records. Do not add survey, interview or person-level files. Required CSV schemas:

| Argument | Columns | Meaning |
| --- | --- | --- |
| `--wards-before` | `Ward,Pop_2025,area_km2` | One row for each of 34 former wards; modelled 2025 population and area in km² |
| `--osm-counts` | `date,ward,metric,value` | Historical OSM ward-category totals; `date` in ISO format; absent ward-category rows are treated as zero |
| `successor_proposal_2025.csv` | `ward,area_km2,proposal_population,proposed_staff` | Planning figures for the 12 successors; proposed staff are not observed positions |

The OSM metrics used are `shop`, `food_outlet`, `religious_premises`, `education`, `health`, `public_space`, `marketplace`, and `road_km`. The latest `date` supplies the manuscript's stock comparison. Figure 1 additionally needs a 34-feature former-ward GeoJSON with a `Ten` name field and a valid CRS; it is optional because the ward geometry is not redistributed into invented successor polygons.

## Run

Python 3.10 or newer:

```bash
python -m pip install -r requirements.txt
python sensitivity.py --wards-before data/table13b_wards_before.csv \
  --osm-counts data/osm_ward_year_counts.csv --output-dir outputs
python build_figures.py --wards-before data/table13b_wards_before.csv \
  --osm-counts data/osm_ward_year_counts.csv \
  --results-json outputs/sensitivity_results.json \
  --ward-geojson /path/to/ThuDucCity_ward.geojson \
  --locator-geojson /path/to/vietnam_outline.geojson \
  --output-dir outputs/figures
python proposal_analysis.py --input data/successor_proposal_2025.csv \
  --output-dir outputs
python ward_heterogeneity.py --wards-before data/table13b_wards_before.csv \
  --output-dir outputs
python verify_public_repo.py
```

Omit `--ward-geojson` to build Figures 2–4 without GeoPandas. The locator outline is optional. `geopandas>=0.14` and `pyproj` are needed for Figure 1. Figure 5 is generated by `proposal_analysis.py`. Output includes `split_allocation_scenarios.csv`, `sensitivity_results.json`, PDF/PNG figures and `Figure4_zero_counts.csv`; `outputs/` is ignored by Git.

The primary 12-ward proposal analysis gives population **53,092–215,638**, area **8.81–34.29 km²**, proposed officials/civil servants **84–120**, and residents per proposed position **603–1,843**. These are design diagnostics. The secondary spatial analysis gives 625 scenarios, population median ratio **2.403–2.940** and area ratio **3.485–4.294**; the 34/12 = 2.833 mean ratio is an arithmetic identity, not a research finding.
